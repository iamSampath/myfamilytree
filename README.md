# My Family Tree

Build your family tree together, with gothrams worked out for you.

## Features

- **Gothrams worked out for you.** Enter each family's gothram once. Everyone in that line gets it, and married women take their husband's gothram while keeping their birth gothram on record.
- **A tree that arranges itself.** Add parents, spouses and children, and the tree lays itself out. Couples are joined, children hang below.
- **Quick adding.** Add a child, spouse or parent straight from any person.
- **Maiden names shown.** Married women show "née Surname" automatically.
- **Build it together.** Invite relatives with a link as an Editor (can make changes) or a Viewer (can only look). Sign-in is required.
- **Private names.** Hide a person's name from Viewers, for example children.
- **Edit history with undo.** See every change, who made it, and undo any of them.
- **Safe from mistakes.** The app blocks impossible links, like someone being their own ancestor.
- **Your data, portable.** Export the whole tree to a file and import it back anytime.
- **Works on phone and laptop.**
